# takeshi

## 米国市場 デイリー市況レポート

毎朝8:00（JST）に米国主要株価指数の市況を自動取得・表示するスクリプトです。

### 取得データ

| 指数 | ティッカー |
|------|-----------|
| S&P 500 | ^GSPC |
| Dow Jones | ^DJI |
| NASDAQ | ^IXIC |
| Russell 2000 | ^RUT |
| VIX（恐怖指数） | ^VIX |

### セットアップ

```bash
# cronジョブを設定（毎日 23:00 UTC = 08:00 JST）
chmod +x setup_cron.sh
./setup_cron.sh
```

### 手動実行

```bash
python3 market_update.py
```
